## Live Fire Learnings (2026-01-11: Lady Kraken vs Winter Club 10U Bronze)

> First field deployment. VibeDeck performed well — one recoverable playback error, no crashes.
> These items surfaced from real game-day usage.

1. **Pause/Play button** — Add toggle to playback bar for instant pause/resume
   - Critical for rapid stop-start scenarios (offsides, quick whistles, goalie covers)
   - Icon toggles: ❚❚ (pause) ↔ ▶ (play)
   - Stop remains separate; always clears all state

2. **Real-time volume slider** — Slider should adjust volume during drag, not just on release
   - Currently fires only on `onSlidingComplete`; should use throttled `onValueChange`
   - Enables fade-out and real-time mixing

3. **Button board auto-padding** — Prevent bottom row occlusion by playback bar
   - When playback bar is visible, add bottom padding to button board
   - Bottom row of buttons must remain fully tappable
